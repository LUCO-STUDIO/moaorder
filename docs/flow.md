# 모아오더 사용자 흐름

## 공통 전제

- 공구 1개 = 상품 1개
- 고객 주 진입: 카카오 링크 공유
- 비로그인 공구 상세 열람 가능
- 로그인: 카카오 소셜 단일 (JWT 7일, httpOnly 쿠키)
- 첫 주문 완료 시 자동 매장 구독
- 알림: 인앱 + SMS/이메일 1채널

---

## 화면 목록 (19개)

**공통 (2):** 로그인, 역할 분기
**고객 (9):** 온보딩, 홈, 공구 상세, 주문/결제, 주문 완료, 주문내역/상세, 매장 구독 관리, 알림 목록, 마이페이지
**사장님 (8):** 온보딩, 대시보드, 공구 생성, 공구 상세(주문 현황), 피킹 리스트, 공구 수정, 알림 목록, 마이페이지

---

## 네비게이션

**고객 하단 4탭:** `홈 | 주문내역 | 알림 | 마이`
**사장님 하단 4탭:** `대시보드 | 공구관리 | 알림 | 마이`
**사장님 FAB:** 대시보드/공구관리 탭에서 공구 만들기 플로팅 버튼

탭 전환: 탭별 스택 유지, 탭 재선택 시 루트 복귀.
매장 구독 관리: 마이 탭 하위.

## 고객 흐름

### 첫 진입 → 첫 주문

```
카카오 링크 탭
→ 공구 상세 (비로그인 SSR)
   상품명, 가격, 사진, 마감 카운트다운
   공동구매형: 진행 현황 바 (7/10명)
   한정 수량: 잔여 n개
   CTA: "주문하기"
→ 주문하기 탭 → 카카오 로그인 (딥링크 보존)
→ 수량 선택 (인라인) + 픽업형이면 시간대 선택
   CTA: "N개 / ₩00,000 결제하기"
→ PG 결제 (포트원)
→ 주문 완료
   주문 요약 + "○○ 매장을 구독했어요" 안내 (해제 가능)
```

### 재방문 → 오늘 수령 확인

```
앱 진입 (로그인 상태)
→ 홈
   [상단] 오늘 수령 예정 (없으면 숨김)
   [중단] 진행 중 주문 상태
   [하단] 구독 매장 공구 피드 (마감 임박순, 품절 제외)
→ 오늘 수령 탭 → 주문 상세 (수령 안내 상단 강조)
```

오늘 수령 노출 기준: 내 주문이 있는 공구가 PICKUP_READY 이상. CLOSED 상태도 "준비중"으로 표시.

### 주문 변경/취소

```
주문내역 → 주문 상세
마감 전: 수량 줄이기(즉시 부분환불) / 전체 취소(즉시 전액환불)
         수량 늘리기 불가 → "새로 주문해주세요"
마감 후~준비중: 취소 요청 → 사장님 승인/거절
수령가능 이후: 취소 불가
```

### 마감/완료 공구 링크 진입

공구 상세 그대로 표시 + 상태 안내 + CTA 비활성.
완료: "종료된 공구예요" / 취소: "최소 수량 미달로 취소된 공구예요"
"이 매장의 진행 중 공구 보기" 유도.

## 사장님 흐름

### 공구 생성 (30초 목표)

```
FAB 탭 → 공구 생성
필수: 상품명, 가격, 마감 시간(빠른 선택: 오늘 오후6시/자정/직접), 사진
고급 옵션(접어둠, 기본 예약주문형):
  타입 변경 → 공동구매형: 최소 수량 / 픽업형: 시간대 추가
  판매 가능 수량, 상품 설명
→ 게시 → 완료 (공유 링크 복사 + 카카오 공유)
→ 구독 고객에게 자동 알림
```

생성 = 즉시 게시 (초안 상태 없음, 임시저장 없음).

### 대시보드 → 주문 확인

```
대시보드
  오늘 진행 중 공구 수, 총 주문/매출
  공구 리스트 (마감 임박순)
  "피킹 리스트 확인" / "취소 요청 n건" 알림 카드
  공구 0개: "새 공구를 만들어보세요"
→ 공구 선택 → 공구 상세 (사장님 뷰)
  주문 현황, 주문자별 리스트 (CRM-lite 정보 포함)
  조기 마감, 공유 링크, 취소 요청 승인/거절
```

### 마감 → 피킹 → 수령 → 완료

```
마감 (자동 or 수동)
→ 마감 트리거:
   공동구매형 미달 → 전체 취소 + 환불 + 고객 알림
   그 외 → 피킹 리스트 자동 생성
→ 피킹 리스트
   총 수량 + 주문자별 목록
   고객별 수령 체크 (optional)
   미수령만 보기 필터
→ "수령 가능" 변경 → 고객 알림
→ "공구 전체 완료"
   수령 체크된 → PICKED_UP
   미체크 → NOT_PICKED_UP (후속 처리 가능)
```

### 마감 후 취소 요청

```
고객 취소 요청 → 사장님 알림
→ 승인: 자동 환불 + 피킹 리스트 갱신
→ 거절: 고객에게 안내
pending 취소 요청 1건만 허용.
```

### 공구 수정 (마감 전만)

제한:
- 가격 변경: 기존 주문 불변, 새 주문부터 적용
- 타입 변경: 주문 있으면 불가
- max_quantity: 현재 주문 수 이상으로만
- 픽업 슬롯: 주문 연결된 슬롯 수정/삭제 불가, 새 슬롯 추가만
- 마감시간/가격/픽업시간 변경 시 주문자 알림

## 상태 머신

### 공구 상태

```
OPEN → CLOSED → PICKUP_READY → COMPLETED / CANCELLED
```

### 주문 상태

```
PAID → CONFIRMED → PICKUP_READY → PICKED_UP / NOT_PICKED_UP / CANCELLED
```

환불: order_adjustments 테이블에서 관리 (주문 상태와 분리).

### 공구-주문 대응

| 공구 | 주문 |
|------|------|
| OPEN | PAID |
| CLOSED | CONFIRMED (마감 시 일괄 전이) |
| PICKUP_READY | PICKUP_READY |
| COMPLETED | PICKED_UP / NOT_PICKED_UP |
| CANCELLED | CANCELLED |

### 고객 라벨

| 상태 | 라벨 | 서브텍스트 |
|------|------|-----------|
| PAID | 주문완료 | 마감 전까지 수정할 수 있어요 |
| CONFIRMED | 주문 확정 | 상품 준비 중이에요 |
| PICKUP_READY | 수령 가능 | 매장에서 수령해주세요 |
| PICKED_UP | 수령 완료 | — |
| NOT_PICKED_UP | 미수령 | 매장에 문의해주세요 |
| CANCELLED | 취소됨 | (사유) |

### 상태 전이 알림

| 전이 | 고객 알림 | 사장님 알림 |
|------|-----------|-------------|
| 공구 게시 | 구독 고객: 새 공구 | — |
| 마감 (성공) | 주문 확정 | 피킹 리스트 준비 |
| 마감 (미달) | 취소 + 환불 예정 | 미달 취소 |
| 수령가능 | 수령 가능 + 픽업 안내 | — |
| 픽업 30분 전 | 곧 픽업 시간 | 고객 픽업 예정 |
| 고객 취소 (마감전) | 취소 + 환불 | 주문 취소됨 |
| 취소 요청 (마감후) | 요청 접수 | 취소 요청 확인 필요 |
| 승인 | 취소 승인 + 환불 | — |
| 거절 | 요청 거절 | — |
| 수령 완료 | 수령 확인 | — |
| 공구 수정 (중요) | 정보 변경됨 | — |

### 취소 가능 범위

| 주문 상태 | 고객 액션 |
|-----------|-----------|
| PAID (마감 전) | 즉시 취소/수량 줄이기 |
| CONFIRMED | 취소 요청 (사장님 승인) |
| PICKUP_READY 이후 | 불가 |

NOT_PICKED_UP: 종료 상태 아님. 사장님이 수령 완료 or 환불 처리 가능.
